# 十位新角色的原创配图

顾承野、季听澜、闻迟、谢无咎、伊莱·沃斯、宋栀夏、许知霁、叶星回、晏绯、艾琳·索尔。五男五女，均为成年设定；晏绯是 216 岁、外貌约 30 岁的成年狐族。

每人一张独立肖像，使用内置 `image_gen.imagegen` 生成，无第三方角色图、无参考输入，没有调用外部按张收费的图片 API。工具没有暴露模型版本，不猜测模型名称。

- [完整提示词](prompts.json)：完全原创的外貌、服装、职业环境与构图设定。
- [生成记录](GENERATION.json)：原图/网站图路径、尺寸、SHA-256、文件大小与人工检查记录。
- `source/` 保留未改动的 PNG；`dist/assets/characters/` 为质量 88 的 WebP 编码，仅转码，没有裁切、缩放或修图。

逐张检查了人物为着衣成年人、单人构图、没有可见文字水印，身份与设定相符。十张网站图合计约 2.22 MB；卡片沿用原页面懒加载，不额外预载十张原 PNG。原貂蝉图不变。
