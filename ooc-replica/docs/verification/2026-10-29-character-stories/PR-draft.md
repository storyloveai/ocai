# Character：原创人物与相遇、对白/旁白分层、记事和对话分支

角色区增加三位原创成年人及六场独立相遇，三张肖像由内置 ChatGPT 出图制作；六位三国人物接入一并包含，目录现在共十二位。对白显示为暖白正体，动作和环境描写为暖灰斜体，流式输出与已保存消息共用展示规则。

对话支持记住原句、按说话者查看/移除记事、从某句话另开走向、改写自己的某句、切回原对话，以及切换独立相遇。记事只继承分叉点之前的内容；已关闭的旧请求无法覆盖新的走向。生成前保存用户原句，生成中刷新后可继续回复，首句入口参数只消费一次。

本 PR 的 base 选 **main**，不依赖旧的 codex/38-chat。新图片原 PNG 和生成记录在 `ooc-replica/character-art/`，网站使用仅做文件编码的 WebP。只改网站角色层，Claude 无需跟改三国剧情、规则或引擎。

验证：`npm run build`、175 项自动检查通过；中英文×电脑/手机 81 项完整流程 + 4 项中断/改写检查通过；展示层对比度、图片路径、场景绑定、记事、分支、恢复和旧人物兼容已检查。浏览器使用本地模拟模型，真实模型对白质感、Firebase 跨设备并发同步尚待 Preview 验收。
