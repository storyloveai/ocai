# Character：原创相遇、连续对话、图文回顾与阅读层级

角色区增加三位原创成年人及六场独立相遇，三张肖像由内置 ChatGPT 出图制作；六位三国人物接入一并包含，目录现在共十二位。对白显示为暖白正体，动作和环境描写为暖灰斜体，流式输出与已保存消息共用展示规则。

对话支持记住原句、按说话者查看/移除记事、从某句话另开走向、改写自己的某句、切回原对话，以及切换独立相遇。记事只继承分叉点之前的内容；已关闭的旧请求无法覆盖新的走向。生成前保存用户原句，生成中刷新后可继续回复，首句入口参数只消费一次。

本 PR 的 base 选 **main**，已合入 b48727a，不依赖旧的 codex/38-chat。新图片原 PNG 和生成记录在 `ooc-replica/character-art/`，网站使用仅做文件编码的 WebP。只改网站角色层，Claude 无需跟改三国剧情、规则或引擎。

新增「回顾」把人物图、当前相遇、记事和最近完整对话组合展示，重复原句只出现一次，能返回原话或继续输入。面板没有额外模型请求或存档写入。整句变化校验会清除原话修改后失效的记事。回复与建议共享连续性指引，区分开场状态、后续事件、提议与已经兑现的行动；行为效果仍需真实模型试玩验证。
