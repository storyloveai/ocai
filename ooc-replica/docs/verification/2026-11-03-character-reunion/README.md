# Character：从当前相遇继续聊（#99）

依赖 Draft PR #95 的十角色目录；本 PR 只增加顾承野、宋栀夏、晏绯三位试点，不变更原貂蝉入口、首屏肖像和布局，不改兰馨内容或三国剧情。

## 试玩

打开 `/assets/character-reunion-preview.html`，任选一个角色。先发送真实消息（例如“今晚先不谈工作。”、“我不买花，只想坐一会儿。”、“我不签契约。”），等回复完成，离开页面后回到同一相遇。点击“接着上次聊”，角色依照实际聊天继续回复；也可以直接输入新话题。

- 打开旧会话不会自动调用模型；接续按钮是界面动作，不伪造一条用户台词。输入框未发送的草稿保留。
- 选择提示来自当前走向里已完成交流的用户原话，可跳回出处。仅有限的明确中英文表达触发提示，**不是通用语义识别或终身记忆**；其他表达仍使用近期上下文和手动记事。
- 最新明确改口会替换同主题的旧选择；用户提议不被视为双方已经同意。自动选择记事不会挤掉已有手动记事。
- 相遇与另开的走向仍各自存档。修改原话会重新计算选择依据。切换语言只控制后续生成，不翻译或篡改历史原话。
- 成功接续、首次交流、五次交流事件只发送角色和相遇标识；不上传对话或选择原文，沿用现有统计开关和 DNT。
