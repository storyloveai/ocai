# 旧角色开场简介的语言修正

针对用户截图：中文会话里，貂蝉大图上方仍显示英文简介。

原因是旧角色首次进入会话时，`scenarios.json` 的英文 `opening` 优先于角色目录里已有的双语简介。角色会话现在使用所选语言的目录简介；创作者自行填写的开场和故事模式保留原有来源。默认访客名跟随语言显示“你”或“You”，已填写的名字不变。原貂蝉大图、布局和历史消息不变。
