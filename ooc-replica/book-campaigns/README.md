# 两部名著互动 · 卷一

本目录是可执行的剧情数据及阅读稿，沿用《三国·谋士》的 CC 规则引擎原件，不改动团队维护的 sanguo/upstream 与 game/sanguo 文件。对白通过现有 DeepSeek 默认配置生成，沿用 Gemini 回退与站内流式打字输出；规则引擎负责数值、门槛、分支与结局。

## 凡人修仙传 · 谷外微尘

玩家沈微尘，27岁，资质平常的新入谷修行者。采用黄枫谷外围的原创支线，不复述全书，不将韩立的秘宝或机缘送给玩家。韩立作为谨慎、独立的客串人物；陶岑、陆晞、叶行舟、乔素与玩家为新写人物。场景、对白、借息契与案件为原创改编内容，不摘录原著章节。原著来源：https://www.qidian.com/book/107580/ 。

| 章 | 内容 | 会留下的决定 |
|---|---|---|
| 一 | 山门与薄册 | 工役、退路与借息，能否只用自己的名字担保 |
| 二 | 坊市的两种价 | 功法完整性、资源开销、是否擅用同伴身份 |
| 三 | 药田无雨 | 病棚与药苗的资源分配，供词是否有证据 |
| 四 | 试炼里的回声 | 三人撤退安排，取材与救人的取舍 |
| 五 | 来收账的人 | 名册外流、真话与合作边界 |
| 六 | 撤离名册 | 借息必须结账；船位不足仍有步行或等候路径 |
| 七 | 能不能再走一步 | 灵力≥8、灵石≥4、经脉≥4才可投入冲关准备；资源不足可延期 |
| 八 | 各自的长路 | 交割记录、同行或分路，承诺有无兑现 |

本卷只完成阶段性积累，不宣称八章走完全书、即刻结丹或成仙。取得灵力与真正完成本卷关口是两种状态，结局同时检查完成标记，不能靠刷数值冒充成功。

## 基督山伯爵 · 余烬与潮汐

玩家诺埃尔·瓦莱特，27岁，原创档案修复员；莉奥娜为28岁原创核验员。唐泰斯、梅尔塞苔丝、维尔福与唐格拉尔保留各自目标。采用1842年改编时间线，年龄与事件顺序作互动化调整，不宣称完全符合原著年表。

| 章 | 内容 | 会留下的决定 |
|---|---|---|
| 一 | 一封迟到的信 | 来源核验、调查预支、委托能否规定结论 |
| 二 | 石墙里的缺页 | 档案缺口与移交链，是否威胁伯爵身份 |
| 三 | 意大利的化名 | 付款关联、邀请身份、合作中的独立性 |
| 四 | 巴黎的门槛 | 银行账目、程序质疑、私人信件边界 |
| 五 | 三条证据链 | 同源传言不充作独立证明；完整副本与有利片段 |
| 六 | 谁会一起倒下 | 委托结算、无涉旧案者去向，不能让预支款凭空消失 |
| 七 | 让证据说话 | 证据≥8、来源已核验、调查余裕≥1才可提交完整链条 |
| 八 | 等待与希望 | 公开、封存或继续调查；记录与关系分别收尾 |

原著底本：https://www.gutenberg.org/ebooks/1184 。中文对白与玩家情节由本项目新写，不复制现代中文译本。证据流程是剧情规则，不是现实法律操作指南。

## 共同机制与边界

- 每卷8章、41场景：16主线、24支线、1个高暴露突发事件。每章最多做一条支线，错过的机会进入记录。
- 每卷4处自由回答问题；AI只分类到已编排的答案或行动，不创造能改变状态的新选项。不足资源的选项显示原因，并保留可继续的替代路径。
- NPC记忆、信任、场景紧张、保护/同行承诺、跨章回响与剧情旧账连续保存。伤害标记不被闲聊刷好感抹去；信任不等于恋爱同意。
- 当前账号下分别使用 ooc-session-v2-mortal-path 与 ooc-session-v2-monte-cristo，侧栏历史可恢复。三国原存档继续使用原键。
- AI请求取消、失败或不完整时不提交临时状态，保留输入；可重试，或明确选择编排文本。编排模式不声称AI生成成功。
- 书封为新写SVG排版，不调用作图API；场景插图待后续接入。当前开放卷一。

运行 `npm run build && npm run check`。规则模拟覆盖每卷1000条路径；UI与接口测试覆盖独立存档、恢复、侧栏不重排正文、流式中断/重试和来源保护。线上浏览器结果另记验收文件。
