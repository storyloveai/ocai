# DeepSeek 原创文字生成与审阅

本批使用当前项目已有的 `/api/chat` 创作接口和服务端 DeepSeek 密钥。没有导出密钥、增加环境变量或建立独立访问凭证。目录格式固定使用 `deepseek-flash`；失败重试同一模型，普通聊天仍保留原有 Gemini 回退。

模型核对：DeepSeek 官方更新日志在 2026-10-17 说明 `deepseek-flash` 对应 DeepSeek-V4.1-Flash-1017。实际记录保留调用别名、时间、请求编号和提示词版本，不能据此声称未来该别名永远固定到此快照。

## 一条内容包含什么

每条都有中英文标题、短简介、展开介绍、序章、起始场景名、可游玩第一幕、玩法说明、三个不同方向的初始行动、世界观与连续性规则、人物的年龄/外貌/口吻/目标/矛盾/关系、后续对话提示词，以及封面和三张详情图的文字方案。

小说侧重世界规则、互相牵制的目标与人物利益。角色侧重职业生活、性格矛盾、相识场景及渐进关系。所有互动人物均为 21 岁以上的成年人；暧昧采用停顿、距离、试探和有分寸的对白，不强加浪漫路线。

## 生成与恢复

在 `ooc-replica/` 运行：

```bash
npm run originals:generate:text -- --concurrency=3
npm run originals:review:text
```

先试样稿可以添加 `--ids=storydate-story-001,storydate-character-002`，或用 `--limit=5`。同版本且校验通过的结果会被跳过，失败单项最多重试四次；重新运行只补缺失或不合格条目。客户端限制并发并将请求间隔至少设为 8.5 秒，沿用服务端原有请求限额。

## 文件与溯源

- `generated-text/storydate-*.json`：逐条结果，保留模型、时间、请求编号、文字与整理记录。
- `generated-text/READING-*.md`：每卷四条的阅读版，展开介绍、开场、人物表与幕后提示词分开。
- `generated-text/INDEX.md`：阅读索引与条目列表。
- `generated-text/QUALITY.json`：结构、字数、年龄、缺失项和开场相似度检查。
- `generated-text/image-jobs.jsonl`：封面与详情图的待执行任务；这只是文字，未调用图片 API。

模型偶尔会把展开介绍写得过短、混用人物全名与简称，或为玩家指定台词。整理程序只会把同一条已生成的世界观补入简介/后续提示词、归一明确的人物简称和图片槽位、移除替玩家说出的台词。改变的字段会保留原值与原因；不会编造缺失人物、年龄或剧情。整理后仍不合格的条目不进入通过清单。年龄与缺失字段检查不会被当成成功跳过。详情图涉及主角表之外的配角时，单列为图像人物参考待审项；涉及玩家时，标记玩家外观待定，不把这些方案误认为可立即生图。

机器检查不等于逐字人工审稿；代表性样稿会另行审读。自然语言里的玩法和连续性约束不是已实现的程序规则。这批文字仍是 `draft_pending_editorial_and_images`，不自动改线上目录、不迁移旧故事会话、不制造播放数、评论或真人作者。
