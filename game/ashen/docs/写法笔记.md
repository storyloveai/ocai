# 写法笔记：同类群像对决小说“为什么好看”（只记手法，不记情节）

> 2026-11-06。用户要求 Claude 读一遍《Fate/Zero》（用户提供的电子书）。Claude 统计了整套书的结构，并细读了序章、第一章开篇和第一场大战。
> 这里只记下可以通用的写作手法，用自己的话写，不引原文，也不借情节、人物和设定。
> 原书的电子书不进仓库。

## 数字

- 四卷正文约 48.6 万汉字，16 个大章，每章 1.5 万–4.7 万字。
- 段落很短：中位数约 37 字，90% 的段落在 93 字以内。
- 对话只占约两成。大部分篇幅是心理描写和战况分析。

## 五个手法（我们要学的）

1. **序章先讲一个人的理想和它的代价**：用讲述者的口吻，像寓言。读者还不知道剧情，就先知道了全书要拷问什么。
   → 《灰烬王冠》的序章：讲六十年前那个改写了世界规则的人，他想要什么、付出了什么。不点名。
2. **人物登场先给委屈，再给野心**：每个主要人物第一次出场，先交代他被谁看不起、被什么夺走，然后才交代他为什么非赢不可。读者先心疼，再站队。
   → 每个搭档的第一场戏都按“伤口 → 执念 → 能力”的顺序写。
3. **打斗写成“双方都在读对方”**：
   - 不只写招式，交手的两个人轮流在心里判断局势：“表面上我占上风，其实不是，因为……”；
   - 能力揭示就是解谜：对手看不懂我的能力，我也在破解他的；
   - 越打，越逼近对方的底牌。
   → 每场对决至少两轮心理判断，换视角写；能力要有一个可以被破解的规则。
4. **一场仗，好几个人在看**：主战场之外，总有第三方、第四方远远观察，各怀心思。读者知道的比任何一个角色都多，紧张感来自这种信息差。
   → 每场主要对决至少切一次“旁观者视角”：伊芙琳、梅洛（棋盘）或者守秘局。
5. **每个阵营都有一套说得通的道理**：没有纯粹的反派。几个人坐下来辩论“愿望该怎么用”，本身就是一场高潮戏。
   → 第二卷安排一场“遗器持有者的谈判夜宴”，用我们自己的形式：在中立的守秘局会议室里摆一张桌子。

## 第二轮：结构和节奏（程序统计 + 细读章节结尾、论战戏）

### 视角怎么轮换
- 全书 78 个场景段，每段平均约 4000–5000 字，**一段一个视角**。普通章节有 4–6 段，在 4–5 个人物之间轮换。
- **两个人物占了视角的四成多**：一个主角，加上一个和他互为镜像的对手。其余十来个人物轮流出场，每人 1–8 段。
- **卷中段放“单视角长章”**：第二卷有连续三章，每章只跟一个人，2 万到 4.4 万字一口气写完。这是集中的大战或者深挖一个人。
- **全书最后一章切得最碎**：12 段，几乎每段换一个人，各条线同时收束。

→ 《灰烬王冠》：
- 林栖和梅洛（镜像：一个要找回被抹掉的人，一个当年亲手抹掉了什么）占四成视角；
- 每章 3–5 段，每段 2000–3500 字；
- 每卷中段安排 1–2 章单视角长章；
- 第六卷最后一章做成快速交叉剪辑。

### 每章怎么收尾（六种钩子，轮着用）
1. **强大存在登场，留一句问话**：新的力量出现，这一章停在它开口的第一句话上。
2. **战斗定格在反转的一瞬**：刚揭穿对手的真本事，刀尖已经到了喉咙前，章结束。
3. **陷阱布好，等猎物上钩**：读者知道计划，被算计的人不知道。
4. **对手起身，踏上战场**：一直按兵不动的人终于出手。
5. **黑暗中有什么在醒来**：不点名的威胁，它的独白。
6. **立誓**：人物在代价面前选了路，一句话收住。

→ 每章结尾从这六种里挑，连续两章不用同一种。

### 论战戏怎么写
- **敌人坐在一起喝酒**：表面客气，甚至有点惺惺相惜，宣战的话就夹在劝酒里说出来。
- **愿望揭晓要出人意料，而且“小”**：最强的人想要的东西，往往比大家以为的朴素得多。这一下就把人物翻了个面。
- **有一个人始终没笑**：第三个人插不上话，在心里否定另外两个人。冲突在沉默里埋下。
- **中间夹一点笑料**：搭档之间的小动作，冲淡沉重，也让人物更可爱。

→ 第二卷“守秘局会议室之夜”按这个写：伊芙琳、白秋、葛兰坐下来谈判，林栖插不上话。

### 搭档关系要各不相同
同类作品里，每一对搭档的相处方式都不一样：有的吵吵闹闹像老友，有的冷冰冰只谈交易，有的一方崇拜另一方，有的互相猜忌。读者会因为“这一对”而追下去。

→ 《灰烬王冠》各组搭档的基调：
- 林栖和提灯：温柔，但互相隐瞒；
- 葛兰和断剑：吵吵闹闹的老酒友；
- 伊芙琳和荆棘冠：主仆颠倒，诗人看不起她；
- 白秋和天平：一真一假，像三个人在下棋；
- 梅洛和棋盘：老朋友，互相怜悯。

## 不学的（那本书的标志）

- 章节开头用倒计时时间戳。我们用“地点 · 时间”的普通小标题。
- 第一场大战放在港口仓库街。我们第一章原定的“旧码头七号仓库”撞上了这个场景，已改成“废弃的海滨游乐园”。
- 召唤历史英灵、职阶、令咒、圣杯、魔术师血统和刻印（设定集里已经避开）。
