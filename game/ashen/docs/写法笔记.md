# 写法笔记：同类群像对决小说“为什么好看”（只记手法，不记情节）

> 2026-11-06。用户要求 Claude 读一遍《Fate/Zero》（用户提供的电子书）。Claude 统计了整套书的结构，并细读了序章、第一章开篇和第一场大战。
> 这里只记下可以通用的写作手法，用自己的话写，不引原文，也不借情节、人物和设定。
> 原书的电子书不进仓库。

## 数字

- 四卷正文约 48.6 万汉字，16 个大章，每章 1.5 万–4.7 万字。
- 段落很短：中位数约 37 字，90% 的段落在 93 字以内。
- 对话只占约两成。大部分篇幅是心理描写和战况分析。

## 五个手法（我们要学的）

1. **序章先讲一个人的理想和它的代价**：用讲述者的口吻，像寓言。读者还不知道剧情，就先知道了全书要拷问什么。
   → 《灰烬王冠》的序章：讲六十年前那个改写了世界规则的人，他想要什么、付出了什么。不点名。
2. **人物登场先给委屈，再给野心**：每个主要人物第一次出场，先交代他被谁看不起、被什么夺走，然后才交代他为什么非赢不可。读者先心疼，再站队。
   → 每个搭档的第一场戏都按“伤口 → 执念 → 能力”的顺序写。
3. **打斗写成“双方都在读对方”**：
   - 不只写招式，交手的两个人轮流在心里判断局势：“表面上我占上风，其实不是，因为……”；
   - 能力揭示就是解谜：对手看不懂我的能力，我也在破解他的；
   - 越打，越逼近对方的底牌。
   → 每场对决至少两轮心理判断，换视角写；能力要有一个可以被破解的规则。
4. **一场仗，好几个人在看**：主战场之外，总有第三方、第四方远远观察，各怀心思。读者知道的比任何一个角色都多，紧张感来自这种信息差。
   → 每场主要对决至少切一次“旁观者视角”：伊芙琳、梅洛（棋盘）或者守秘局。
5. **每个阵营都有一套说得通的道理**：没有纯粹的反派。几个人坐下来辩论“愿望该怎么用”，本身就是一场高潮戏。
   → 第二卷安排一场“遗器持有者的谈判夜宴”，用我们自己的形式：在中立的守秘局会议室里摆一张桌子。

## 不学的（那本书的标志）

- 章节开头用倒计时时间戳。我们用“地点 · 时间”的普通小标题。
- 第一场大战放在港口仓库街。我们第一章原定的“旧码头七号仓库”撞上了这个场景，已改成“废弃的海滨游乐园”。
- 召唤历史英灵、职阶、令咒、圣杯、魔术师血统和刻印（设定集里已经避开）。
