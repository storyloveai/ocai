# 《灰烬王冠》的图（两版：动漫、写实）

同一份剧本、同一份存档，两版画风。播放页右下角“画风”随时切换：先找当前画风的图，没有就用另一版的，两版都没有就显示占位（背景是渐变加名字，立绘是剪影）。

## 目录

| 路径 | 内容 | 尺寸 |
|---|---|---|
| `art/<anime 或 real>/bg/<id>.webp` | 背景（id 见 `content/ch*.py` 的 `BG`） | 1920×1080 |
| `art/<画风>/cg/<id>.webp` | CG，`cg/title.webp` 是标题画面 | 1920×1080 |
| `art/<画风>/sprites/<人>/<表情>.webp` | 立绘，透明底；某个表情没画时用 `normal` | 高 1536 |
| `art/m/<画风>/...` | 手机用的小图（1280×720），收图工具自动生成 | |

## 出图单

`python3 game/ashen/art/make_jobs.py` 生成 `jobs-anime.jsonl` 和 `jobs-real.jsonl`，各 76 条（卷一七章）：人物立绘（先标准立绘，再按剧本实际用到的表情出差分）、背景、CG（含标题）。清单从剧本里算出来，剧本加了场景就重跑。

- 两版的提示词只写画风特征，不写任何画师、公司、作品的名字。
- 所有人物都是成年人。写实版的人脸不能是真人照片、不能像名人。
- 主角林栖不出立绘（玩家视角），只在 CG 里出现，外形见出图单里的说明。

## 收图

用户已经让 GPT 出了一批图（偏动漫和偏写实各一部分）。拿到以后：

1. 按出图单的 `name` 对号：每张图属于哪一条、哪一版。
2. `python3 game/ashen/tools/adopt.py anime 源图.png bg/ferris`（可以一次给多对）。
3. `python3 game/ashen/tools/build.py` 重新打包页面。

对不上号的图先放 `art/candidates/<画风>/`，不打包进页面。
