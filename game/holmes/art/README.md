# 《贝克街》的图

和《汐川》同一套流程：Codex 出图，Claude 审图，用户定标准立绘；收图用 `game/xichuan/tools/adopt_art.py`（原图 + 手机小图 + 2.5D 深度图）。

- 目录：`bg/<id>.webp`（1920×1080）、`sprites/<人>/<表情>.webp`（1024×1536，透明底）、`cg/<id>.webp`（1920×1080）。
- 画风：和《汐川》一致的现代日式 galgame 风，色调换成维多利亚伦敦（雾灰、煤烟棕、深绿、煤气灯的暖黄）。
- **不像任何影视、游戏、漫画版的福尔摩斯**：不戴猎鹿帽、不叼弯烟斗、不披因弗内斯斗篷，长相不像任何演员。人物外形只按原著描写来。
- 华生是玩家，不画脸：CG 里只出现背影或手。
- 所有人都是成年人；不画血腥（案发现场只有墙上的字和蜡烛）。

## 批次

1. **第一批**（`jobs-batch1.jsonl`，19 条）：卷一试样的 8 个标准立绘（福尔摩斯、雷斯垂德、葛莱森、哈德森太太、杰弗逊·霍普、艾琳·艾德勒、杰贝兹·威尔逊、约翰·克雷，各出 4 个候选）+ 11 张背景（各 2 个候选）。
2. **第二批**（`jobs-batch2.jsonl`，25 条）：
   - 卷一剧本里新出场的 3 个人的标准立绘：巡警约翰·兰斯、“索耶太太”、斯坦福。各出 4 个候选。
   - 剧本实际用到的 16 个表情差分：福尔摩斯 4、雷斯垂德 4、霍普 3、葛莱森 2、索耶太太 2、兰斯 1。要等对应的人定了标准立绘再出，拿标准立绘当参考图，只改表情，不挪位。
   - 6 张 CG：初次见面、墙上的字、卷尺与放大镜、霍普落网、日记（结局）、标题画面。剧本里已经接好位置，没有图时构建会用占位图。

候选放 `art/candidates/<批次>/`，开 PR，不要直接改正式目录。
