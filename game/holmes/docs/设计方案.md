- **全本**：柯南·道尔全部 60 个故事（4 部长篇 + 56 个短篇），原著已进入公版。
- **引擎**：直接用 WebGAL（决策记录 xichuan v0.27）。AI 自由对话、决裂、2.5D 由 Claude 移植进 WebGAL。

- **先做第一卷试样**，用户试玩满意后，按同一套模板批量做完。

## 底本和版权

- **英文**：用原著原文（Project Gutenberg / sherlock-holm.es）。对话尽量原句照用，叙述部分为了适合 galgame 会压缩改写。原著是公版，这样做合法。
- **中文**：自己翻译，不用任何现成的中文译本，因为译本可能有版权。
- **不用的东西**：BBC《神探夏洛克》、格拉纳达剧版、盖·里奇电影等后来改编作品里新加的设定、外形和台词，一概不用。人物外形以原著描写为准，参考 1890 年代 Sidney Paget 插画的时代感（已公版），画风仍是我们的现代日式 galgame 风。
- “Sherlock Holmes”作为 App 名或商品名，上架前要查一下商标。

## 核心玩法：一个案子怎么玩

原著的凶手、真相和结局都**不改**。玩家改变的是：华生自己看穿了多少、和谁的关系怎么样、以及他在路上的经历。

1. **委托**：委托人上门，交代案情（原著开场）。
2. **勘查**：现场有几个可以查看的地方，每查到一样东西就记一条**线索**。线索不全也能往下走，只是推理时可用的少。
3. **盘问**（AI 自由对话，复用汐川的机制）：
   - 每个证人或嫌疑人都有自己“知道什么、瞒着什么、什么情况下会说”的设定。玩家问到点子上，就解锁一条证词线索（相当于汐川的“隐藏的门”）。
   - 嫌疑人会撒谎。他说的话和已有线索对不上时，玩家可以当场拿线索戳穿他。
   - 说话出格会被赶出去，那个人之后不再配合（相当于汐川的决裂）。福尔摩斯和警探对你的评价也会跟着变。
4. **推理**：福尔摩斯揭晓真相前，华生要先回答几个问题，比如谁、怎么做的、为什么、证据是哪条，从手里的线索中挑答案。答对多少决定这一卷的**推理评级**：
   - 抢先看穿：福尔摩斯罕见地夸你一句（有专属台词和 CG）
   - 跟上了
   - 被蒙在鼓里：原著式的“华生，你看了，但你没有观察”
5. **揭晓**：福尔摩斯讲出真相，用原著对白。

**贯穿全本的关系**：
- 福尔摩斯：信任、敬重。会影响后面几卷他肯不肯带你出门、肯不肯先告诉你计划。
- 雷斯垂德、葛莱森两位警探：他们会不会把案子透露给你。
- 哈德森太太。
- 情感线角色。

这些都由规则计算。AI 只负责给玩家说的话打标签、写台词（和三国、汐川同一条规矩）。

## 恋爱线（请确认）

在“玩家是华生”的前提下，原著里有情感线的是：

- **玛丽·摩斯坦**（卷二《四签名》）：原著中华生的妻子，恋爱主线就是她。之后几卷是婚后生活；到《空屋》时，原著交代她已去世。这条要不要照原著写、怎么写得克制，需要你定。
- **艾琳·艾德勒**（《波希米亚丑闻》）：原著里她是福尔摩斯心中“那位女士”，而且在同一篇里嫁给了诺顿。让华生和她谈恋爱，会和原著冲突。**建议**：对她做“敬重 / 较量”，不做恋爱。
- 其他（比如《铜山毛榉》的维奥莱特·亨特）原著只有暗示，**建议**不做。

所有人物都是成年人，不写露骨内容。

## 技术路线

- **剧本**：沿用 `game/engine` 的规格 0.4。内容写在 `game/holmes/content/*.py`，生成 `campaign.json`，必须通过 `check.mjs`。新增“线索”“推理问答”两个机制，需要给引擎加功能，到时单独提 PR。
- **WebGAL**：用 `webgal_export.py` 的通用版把剧本导出成 WebGAL 剧本。AI 对话、线索本、推理问答要在 WebGAL 上做插件（可能需要 fork）。2.5D 做成 WebGAL 的立体滤镜加陀螺仪。
- **出图**（老规矩）：Codex 出候选，Claude 审，用户定标准立绘。生产线：`jobs-*.jsonl` → 候选 → `adopt_art.py`。
  - 卷一需要：福尔摩斯、华生（玩家，不露脸）、雷斯垂德、葛莱森、哈德森太太、杰弗逊·霍普的立绘，以及贝克街 221B、布里克斯顿路空屋、伦敦街道等背景和关键 CG。
