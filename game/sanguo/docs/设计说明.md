# 设计说明：三国·谋士 卷一

## 1. 为什么重做

v0.3 让玩家扮演名人本人，每个名场面单独成局。试玩反馈是“这样玩三国不好玩”。原因有两个：

- 玩家知道历史结局，选什么都缺悬念。
- 场景之间没有延续，前面的选择不会带到后面。

v1.0 改用研究文档第 5.3 节的方案 B：玩家是原创谋士，名场面是他可以插手的节点。悬念从“历史会不会变”转到了另外三件事上：

- 事情以什么方式发生。
- 谁付出代价。
- 谁欠了谁的情。

## 2. 一章怎么跑

```
章节开场 → 导演从剧情单元池里挑 2–3 个给玩家（“这段日子你只来得及做一件事”）
        → 玩家选一个支线 → 主线名场面 → 下一章
```

- **导演打分**：基础显著性 + 2 × 条件具体度 + 3 × 可兑现的回响数。得分最高的几个支线会被提供给玩家。打开创作者视图，可以看到每一章的打分表。
- **错过也记账**：没被选中的支线，会以“错过”写进账本。

## 3. 五个机制与研究文档的对应

| 机制 | 页面上看到什么 | 引擎里是什么 | 研究文档 |
|---|---|---|---|
| 事件账本 | 右侧“记事”，以及每个关系值点开后的证据 | `ledger`：只追加，每条记录写明谁改了什么、因为哪个选择 | §6.1 |
| 回响 | 标着“回响”的段落，下面写明“因为：……” | 选项用 `echo` 登记回响，后面场景的 `callbacks` 负责兑现；待兑现的、最近登记的优先，每个场景最多两条 | §5.4、§6.1 |
| 叙事债务 | 创作者视图的债务表，选项后面的变化记录 | 选项用 `debt` 开债，用 `resolve` 以替换、绕行或取消的方式处理；场景的 `on_enter` 可以兜底 | §5.5、§6.2 |
| 保留等级 | 创作者视图里每个场景的标签：原文保留、作用保留、自由改编 | 节点上的 `lock` 字段 | §5.5 |
| 结局片段 + 溯因 | 尾声每一段下面的“为什么？” | `CC.endings`：每组取第一个成立的片段；`CC.why`：从账本里找出改过相关变量的选择 | §7.2 |

### 四笔叙事债务（都已在内容里处理）

| 债务 | 什么时候产生 | 怎么处理 | 玩家看得见的差异 |
|---|---|---|---|
| 通关文书 | 托温芷弄到文书 | 替换：洛阳的韩福不认文书，过关的传奇照样发生 | 孔秀活了下来；温芷被问了三天话 |
| 走马荐诸葛 | 告诉徐庶真相，他留了下来 | 绕行：徐庶和你一起举荐，或者刘备凭水镜先生那句话自己去 | 徐庶留在新野，他的母亲被软禁在许都 |
| 连环计 | 提前举荐庞统 | 替换（庞统照样去诈降），或者绕行（蔡瑁出主意，曹操自己连船） | 庞统留在刘备帐下；结局里会提到落凤坡 |
| 糜夫人 | 和赵云一起回去找人 | 替换：赵云照样单骑救出阿斗，你带夫人走小路 | 糜夫人活了下来，你肩上中了一箭，第七章能做的事因此受限 |

## 4. “先见”：玩家知道结局，这件事本身也是机制

标着“先见”的选项，用到了玩家对原著的了解，例如预言衣带诏会泄露、提醒温芷离开水寨。玩家自己打字时，说出还没发生的事（“赤壁会有一场大火”）也算。

每用一次，异名 +1，身边的人会察觉。异名到 2，结局里会出现“坊间传说你能知未来”。诸葛亮的戒心也会随之上升。

这样一来，知道结局不再让选择失去意义，而是变成一种要付代价的资源。

## 5. 自由输入的边界

- 模型（`sample`，quick 档）只做两件事：
  - 把玩家的话映射到现有选项。
  - 写一两句在场人物的反应，不改变任何状态。
- 生成的反应要过三道检查，不通过就退回固定文本：
  - 长度
  - 语言是否和界面一致
  - 有没有提到未来的人名或事件（`future_terms` 按章节解锁）
- 没有 AI 时，用中英文双字词的匹配兜底。

## 6. 模拟结果（5000 局随机玩家，节选）

完整结果见 `模拟报告_自动生成.txt`。

- 平均每局经历约 12 个场景，出现了 1100 多种不同的结局组合。
- 刘备线 86%，曹营线 14%。
- 回响兑现率：每一条回响都在 60% 以上，大多数是 100%。
- 结尾时还没处理的债务：0。

需要真人校准的地方：

- 温芷线在随机策略下只有 4% 能走到“接回温芷”。这是一条需要玩家主动经营的线，要等真人试玩才知道这个比例是否合适。
- 曹营线的入口比较窄：要先获得曹操的赏识，再在“挂印封金”时选择留下。

## 7. 配图怎么参与机制（v1.1）

| 做法 | 例子 | 对应的机制 |
|---|---|---|
| 选择之后画面会变 | 赤壁选“去接温芷”后出现提灯小船；连环计时附和程昱，下游会多出一排没连锁的船；长坂选“疑兵”后，林中扬起尘土 | 让后果被看见（§5.4） |
| 进场时，画面就带着之前的状态 | 你提醒过温芷，赤壁的后营就是空的，否则后营在烧；华容道队尾出现背药箱的女子 | 带状态的汇合（§7.3） |
| 支线卡片带缩略图 | 导演提供的剧情单元，直接用画面来挑 | 剧情单元池 |
| 舆图 | 刘备线：许都→下邳→古城→新野→长坂→赤壁→华容；曹营线：一路留在许都 | 让大格局分叉被看见 |
| 人物印章 | 用印章代替画脸；原创人物温芷用圆形粉色印 | 避免把名人画得不像，也区分了原创人物 |
| 尾声画 | 同舟、江边茅屋、城郭、独立江岸、梅枝，由结局变量拼出来 | 结局片段 |

## 8. v1.2 的改动

### 8.1 夜谈：把 StoryDate 的对话体验接回来

- 共 7 场夜谈，安排在章节的主线事件之后，按条件出现：
  - 篝火边和关羽。
  - 古城楼上和刘备。
  - 灯下和诸葛亮。
  - 宴后和曹操。
  - 江边和温芷。
  - 华容道之后和关羽。
  - 北归路上和曹操。
- 每场有 2–3 句的额度。话题由规则支撑：点一个话题，得到固定回答，并带来相应的关系变化，每个话题只能聊一次。
- 自己打字时，模型先判断这句话是不是在说某个话题：
  - 是：按话题处理。
  - 不是：由角色即兴回一句话，不改变任何状态，但同样消耗一句额度。
- 每个角色都有一段人设（`chars.*.persona`），模型生成回答时只用这段人设、当前关系值和场景，并且禁止提到之后才发生的事。
- 夜谈里也能登记回响。例如关羽在篝火边说“最怕负了大哥”，土山、挂印封金、华容道之后都会回响这句话。

### 8.2 风险：会输了

| 危机 | 触发条件 | 可以怎么选 |
|---|---|---|
| 冷落（刘备线） | 刘备信任 ≤ 1 | 请辞，卷一提前结束；留下当小吏，之后每章只给 1 个支线；请命做苦差，需要忠义之名，成功后信任大涨 |
| 闲职（曹营线） | 曹操赏识 ≤ 1 | 外放，提前结束；坐冷板凳；连夜写方略，需要权谋之名 |
| 妖言（两条线都有） | 异名 ≥ 4 | 说实话“梦见过”，卷一提前结束；说是推算，需要诸葛亮敬重 ≥ 3 或曹操赏识 ≥ 6；矢口否认，主公信任大降 |

另外新增 5 个“先见”选项，都是收益大、风险也大的选择：

- 劝刘备连夜离开许都。
- 断言袁绍必败。
- 抢在诸葛亮之前先说出三分天下。
- 预先安排赵云专护家眷。
- 在夜谈里提醒曹操提防东南风，或者用三分天下试探诸葛亮。

有 3 个选项改成需要关系值才能解锁：

- 长坂坡回去找家眷，需要刘备信任 ≥ 4。
- 赤壁帮诸葛亮调度伏兵，需要诸葛亮敬重 ≥ 1。
- 华容道替关羽作保，需要关羽敬重 ≥ 3 或刘备信任 ≥ 6。

### 8.3 四种目的明确的模拟玩家

`npm run check` 现在除了随机玩家，还会各跑 1000 局四种类型的玩家，检查每种玩家能不能走到自己想要的结局：

| 类型 | 目标 | 结果 |
|---|---|---|
| 感情型 | 和温芷在一起（成亲、接回、成家、救下） | 100% |
| 忠义型 | 刘备视为心腹，并且以忠义著称 | 100% |
| 权谋型 | 留在曹营并被列为心腹 | 67%；以权谋著称 100% |
| 先知型 | 被称为“能知未来” | 100% |

随机玩家里，约 8% 会因为“先见”用得太多被当作妖人，提前结束。

### 8.4 原文引文核对

中文引文按 NTD 古书连载的版本，逐字核对了第 21、25、35、36、38、41、42、48、49、50 回，并修正了两处：

- 张飞桥上那声大喝，原文是“我乃燕人张翼德也！谁敢与我决一死战？”。
- 华容道上曹操的问候，原文是“将军别来无恙？”，后面答话的是“云长”。

赵云那句军令只保留了核对过的原话。这个版本和人民文学出版社等通行本可能还有个别标点差异，正式发布前建议再用纸本复核一次。
