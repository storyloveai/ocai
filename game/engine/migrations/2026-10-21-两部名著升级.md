# 网站上两部名著升级到引擎 0.4

写给 @Lindsey-cyber / @allliiita。对象是 `ooc-replica/book-campaigns/` 里的《谷外微尘》和《余烬与潮汐》。下面的结果都是在你分支 `feat/ooc-high-fidelity-replica` 的 `fb3dd2d` 上实际跑出来的；你的文件我一个都没改。

## 第一步：换掉冻结副本（零改动，现在就能做）

把 `ooc-replica/book-campaigns/engine/campaign_core.js` 换成 `game/engine/campaign_core.js`。

已验证：
- 两部书的数据一个字不改，校验 0 个错误，1000 局模拟没有阻塞问题。
- `tests/book-campaigns.test.mjs` 里直接调用引擎的三个测试（校验和模拟、花费门槛和里程碑、暴露插曲和背叛）全部通过。
- 新引擎会多出 15 条提醒：每个人物缺两根轴、关系值上限是 8 而不是 10。这是 0.4 的要求，0.3 的书只提醒、不拦。

换上以后，三国这边对引擎的每次改进（跨卷回落、五档、预算统计、连卷模拟等）你那边都能直接用到，不会再分岔。

## 第二步：数据升到 0.4（改 `catalog.mjs` 里的 `shell()` 和两处门槛）

用升级工具跑出来的结果（`game/engine/tools/migrate.mjs`）：

```
node game/engine/tools/migrate.mjs mortal-path.json out.json --pack cultivation \
     --res power=qi --res currency=stones --res body=health --res risk=exposure
node game/engine/tools/migrate.mjs monte-cristo.json out.json --pack mystery-revenge \
     --res proof=evidence --res currency=funds --res time=time --res risk=exposure
```

两部书升级后都是 **0 个错误**，三条题材包规则也都通过：
- 花资源的场景都有不花资源的路；
- 结局不只看灵力或证据；
- 暴露到线会触发场景。

你那边写书时已经自己守着这几条，现在由校验器替你把关。

因为两部书的数据都由 `shell()` 生成，源码里要改的地方很少：

1. `shell()` 里：
   - `spec` 改成 `'storydate.campaign/0.4'`；
   - 加上 `tiers`、`pack`、`resources`（从 `game/engine/tiers.json` 和 `game/engine/packs/*.json` 读）；
   - 每个人物的 `dims` 加上 `warmth`、`esteem`；
   - 关系变量的上限从 8 改成 10，新加的两根轴从 2 起步。
2. 门槛对齐到档：
   - `ge('rel.'+partner+'.trust',5)` 改成 `6`（倚重）；
   - `ge('rel.'+id+'.trust',4)` 保持 `4`（可托）。
3. 资源对应：

   | 书 | 题材包 | 资源 |
   |---|---|---|
   | 谷外微尘 | `cultivation` | 修为 `qi`、资源 `stones`、身体 `health`、风险 `exposure` |
   | 余烬与潮汐 | `mystery-revenge` | 证据 `evidence`、经费 `funds`、时间 `time`、风险 `exposure` |

## 升级后检查工具发现的问题（不阻塞，但值得看）

`node game/engine/tools/check.mjs` 的关系预算表和模拟结果：

- **交情和看重从来不动。** 现在只有信任在变。要让它们动起来，有两种办法：
  - 选项上标题材包的价值观标签：修仙用稳、贪、义、狠、诚、悟，悬疑用真、忍、利、情、义、狠；
  - 给人物写价值观：每个标签让哪根轴 ±1。

  在场的人会按自己的价值观自动反应，不用在每个选项里手写关系变化。
- **很多回响兑现率偏低**，在 0% 到 53% 之间。比如《余烬与潮汐》的 `independent` 一次都没兑现，`formal` 和 `redact` 只兑现了 24%。说明前面的选择在后面常常没有被提起。
- **有几个结局随机玩家从来走不到**：
  - 《余烬与潮汐》的 `companion.apart`、`rel_villefort.trusted`、`rel_danglars.trusted`；
  - 维尔福和唐格拉尔的信任几乎不涨（6% 和 37% 的局动过，最高只到第 1 档）。

  如果是有意为之（反派本来就不会信你），可以把这两组结局删掉。
- **陆晞的信任偏容易涨**：28.7% 的局到了最高档，其余人物大多停在第 0 到 1 档。
