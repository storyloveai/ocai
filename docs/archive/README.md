# Historical recovery scripts

These scripts are preserved from the 2026-10-10 checkpoint for reference. They contain paths from previous workspaces and apply string replacements to older frontend versions. Do not execute them against the current application. The current frontend is already committed in dist/app.js.

The previous static builds are represented by repository commit d842a7ab81d1261725b12dd23b45e2589507e21b. The original checkpoint ZIP also retains the historical ZIP/TAR packages.

Research files in ../research are historical notes and optional design examples, not implementation requirements or verified current product information.
