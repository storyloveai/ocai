# 聊天免费、积分和后续收费的建议

2026-11-12，接续 #148 / #149。以下是产品建议，未启用扣积分、免费日额度或新收费点。

现在先保留基础聊天免费，适合 10—20 人的小范围体验，验证角色吸引力、进入故事和再次回来。公测前需要明确免费额度与超额权益。基础的角色一致性和剧情记忆属于产品承诺，建议继续包含在基础体验里。

建议顺序：内测免费体验 → 根据真实成功回复用量确定每日免费额度 → 超额长聊采用积分或会员权益 → 验证精品新章节、额外路线或番外的内容付费。推荐回复是辅助功能，建议成本计入服务成本，不作为一次独立扣费。已有免费内容和进度的处理要先明确，再设计新内容解锁。

## 当前代码的真实状态

- `server/wallet.js` 只有查询、购买入账和每日签到；没有聊天消费接口。签到目前每天赠送 100 积分。
- 购买档位目前为 200 / $1.99、2500 / $19.99、5000 / $29.99。积分目前能买、能领，聊天不扣。
- `/api/chat` 目前按同源和短期限流接收请求，没有按 Firebase 用户身份做钱包消费结算。
- 因此，确定每条扣多少之前，需要一并确定赠送政策、免费额度、成功回复口径，以及模型/回复长度是否有价格区别。这次保留当前规则。

## 先把成本看清楚

新增 `ai_usage` 服务端日志，每个供应商尝试分别记录输入、输出、缓存读取、推理 token 和完成/失败/取消状态。按现有 SDK 开启 DeepSeek 的流式 usage 回传；不记录台词、提示词、账户 ID 或密钥。

成本汇总：`cd ooc-replica && node scripts/chat-cost-report.mjs /path/to/sanitized-usage.jsonl`。输入为导出的 JSONL 用量记录，输出按 chat / suggestions / author 分组的估算，不打印记录内容。

截至本日，DeepSeek 官方 `deepseek-flash` 高峰每百万 token：输入未命中缓存 $0.30，缓存命中 $0.006，输出 $1.20。[官方价格](https://api-docs.deepseek.com/quick_start/pricing/)。工具采用高峰费率保守计算，缓存未知按未命中计算；此日期之后应复核费率。

仅作假设示例：一次回复输入 10,000、输出 500 token，完全未命中缓存，模型费约 $0.0036。它不是本站实测均值，也不包括同轮推荐回复、重试/备用模型、游戏内自由对话、出图、托管、存储、支付手续费和税费。当前只覆盖 `/api/chat` 的调用；Gemini 等未知模型、没有返回 usage 的失败/取消尝试会列为未知，不会按零费用处理。没有完整实测前不据此定零售价。

建议观察：每位用户每天成功回复数、单轮主回复加推荐的成本、长会话成本变化、失败/取消/备用模型占比、剧情回聊和次日留存。角色价值与成本一起决定付费边界。

## 真正扣积分时的工程要求

在独立评审里确定价格和赠送额度，再接服务端认证、原子余额预留、成功结算与失败释放；请求需幂等，重复提交或回调不重复扣费。建议用户取消、失败、只有半截的回复不扣零售积分，上游已发生的成本仍记录。发送前明确显示本次消耗，余额不足时保留草稿和历史。实际付费调用、充值和发布扣费规则仍需用户明确授权。
