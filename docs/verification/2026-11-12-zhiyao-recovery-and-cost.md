## 修复和补充

1. 云端首次读取失败时，新增或修改的数据先保存在当前账号的设备缓存中，不自动覆盖未知云档。待重试读取成功后，内容相同自动确认；云端为空可同步；两份不同则显示版本比较，用户明确选择后才继续。替换前保留最多三份账号隔离的本地备份。
2. 补上重试连接和版本选择界面。原有 `#account-status` 在当前网站外壳内被 CSS 隐藏，所以另设真正可见的同步状态提示。
3. 旧账号的迟到写入失败不再污染新账号的状态；保存进行中再修改其他记录时，两个未同步标记都会保留，避免刷新丢掉其中一个。
4. 聊天成功/失败/主动停止分开记录，游戏实际开始、选项点击和续玩通过同源 iframe 事件传递；回聊导航标记只消费一次。口径见 `docs/analytics/2026-11-12-zhiyao-loop-funnel.md`。
5. `/api/chat` 记录按供应商尝试分开的 token 用量，并提供离线成本汇总脚本。未知用量和未知备用模型不计为零。付费建议见 `docs/product/2026-11-12-chat-monetization.md`；没有开启扣积分。
