# 角色与故事入口减法验收

2026-11-17，任务 #156 / PR #157。继续 `codex/character-loop-integration-20261116` 集成预览，base 为 main；没有合并、关闭或改动源 PR #149 / #151 / #155。用户要求收掉角色下面的“故事世界”和“创作”分区，角色直接联动网站原有故事。

## 用户现在看到什么

- 角色目录保留原貂蝉大图、渐变、对白和回复输入，下面直接是角色筛选与封面卡。删除局部“角色 / 故事世界 / 创作”导航、独立世界目录和框架演示，首页也不再追加重复的世界入口。
- 筛选名称使用已存在的作品名。人物档案的出处直接进入 `/story/<作品 id>`；原有故事详情和预览里反向显示同一批人物。主按钮仍直接进入原游戏，旧的三国人物传记也保留，没有再造第二套故事页。
- 从目录、聊天或故事进入人物，返回时保留实际来源。已停用的世界、框架书签转到原有作品或首页；旧角色 ID 和聊天存储键保持兼容。原型创作草稿仍可从旧 `/studio` 导出，角色目录不再推广该入口。
- 全站搜索与角色目录共用 33 个角色，去重旧卡片别名；中英姓名、简介、原有故事名均可搜索。角色搜索结果用同样的场景与封面构图。搜索显示资料不混入模型可用角色、作品库存或私有会话。
- 隐藏没有实际作用的通知、屏蔽设置、模型质量档位和“今日”分类；客服未配置时明确说明未开放。聊天设置删掉两个无消费者开关、虚构画廊计数、无效的头像/预览入口、未实现的快捷键说明及红点，只保留真实单图查看和聊天操作帮助；有作者玩法提示时，在同一帮助弹窗显示原文，不进入模型上下文。积分页和真实积分记录入口保留，报价与计费流程不变。
- 创作仍从“我的作品”进入原编辑器。编辑器自己的三个步骤、帮助和验证提示补齐双语，切语言不重建表单，也不翻译用户写的标题、正文和聊天原话。
- “我的作品”的中文状态、数量、体验/编辑按钮与筛选值分离，翻译后仍可正常筛选和排序。个人资料只编辑真正被消费的称呼和内容偏好；旧 `All` 偏好显示为模型支持的 Neutral。没有消费者的自我介绍输入撤下，旧值仍保留。
- 汐川保留游戏原生语言按钮，切换时同步网站与宿主文案，移除重复的宿主语言按钮。当前 iframe、对白、存档及可选 AI 勾选状态不因语言切换重置；手机高度随顶栏和费用提示实际高度调整。

## 顺着动线修到的断点

- 自己发布的作品和已体验的社区作品曾会从历史列表消失。列表现在共用一套解析：现有目录、自己的已发布作品、曾访问过的公开作品标题快照。没有访问过、无法解析的旧 ID 不编造内容。
- 公开作品快照只保留展示所需的 id、标题、类型和封面；最多 200 条，仅本设备、当前账号作用域，不上传云端，不存私有提示词或正文。每次打开仍重新请求原公开接口；撤回、404 和失败不使用快照继续播放。
- 修复远程加载期间切换页面后，迟到的失败结果覆盖新页面。请求绑定完整路径、账号和本次加载；旧 episode 链接仍可用，类似前缀的其他路径不冒充同一页面。
- 私有发布作品的会话标题返回“我的作品”，他人的公开作品返回社区；不再进入不存在的 `/story/u-*` 详情。
- 三国人物传记的档案 → 原故事 → 播放 → 标题 → 档案保持人物来源；从首页独立进入其他故事不会继承旧人物返回地址。
- 手机聊天左上角原来没有行为的箭头改为真实返回链接：角色档案、完整故事详情、自建作品列表或社区。沿用同一站内路由及来源上下文，双语标签和 44px 点击区，不新增抽屉。
- 编辑器的站内离开、浏览器返回和刷新加入未保存保护；取消或关闭确认框保持同一表单，保存失败不离开，发布完成后的体验入口不被误拦。保存草稿不等于更新远端公开版本。显式登录 / 退出也先保护未保存内容；账号恢复期间暂时禁用同一表单，恢复后原位继续。
- 已发布作品的待选可见范围和服务器已生效状态分开。保存私密草稿不会假称远端作品已隐藏；真实更新 / 撤回成功才改有效状态，失败保留原状态并允许重试。通过真实 titles handler 与模拟 Firestore 验证撤回生效，没有访问生产数据。

## 自动与浏览器验收

- `npm run build` 成功，完整 `npm run check` **360 / 360** 通过；`npm run game:check` 确认副本与游戏源文件一致。
- 角色、Story 和编辑器三份独立 CSS 经 esbuild 解析无警告，`git diff --check` 通过。
- 回归覆盖真实 DOM / worker 导航、双语筛选值、用户原文保护、来源返回、旧 episode、账号作用域、公开作品访问重查、迟到结果、游戏语言 / 高度、创作未保存离开与有效可见性。原有模型报价 / 计费门禁继续通过，没有为静态视觉规则堆字符串断言。
- 本轮没有游戏源文件变更；不重复计入此前的引擎模拟次数。提交后的 GitHub / Vercel 状态及线上预览检查记录附于 PR #157。

Chrome 使用 1366×900 和 390×844，中英双语。本地访客站的配置明确为 `configured:false`，所有生成 POST 拒绝；账号、作品撤回及迟到失败使用独立的模拟身份 / 模型 / 钱包服务器。没有往浏览器注入存档、账号或 localStorage。

实际操作覆盖：

1. 目录 → 夏知遥 / 沈澄 → 原汐川详情 → 游戏，反向从故事找到人物并返回；手机无横向溢出。
2. 原生游戏从序章开始，选“来看它最后一个春天”，推进到第一章，切英文后对白仍停在同一句，聊天承接第一章进度。
3. 在本地模拟站创建并私下发布测试作品，实际聊天后历史及侧栏显示正确；切到 Bob 后没有 Alice 的作品，切回恢复。
4. 社区作品体验后出现在历史；模拟撤回后重新打开显示不可用，没有缓存续玩。模拟延迟加载失败后马上进入游戏，旧失败没有覆盖游戏。
5. 中文搜索夏知遥得到唯一角色；英文、中文切换更新名字、说明和结果数，用户自己的标题与原话保持不变。
6. 创作输入未保存标题 → 浏览器返回 → 继续编辑：输入仍在；再从页头离开选择不保存，列表仍是旧标题。另实际“保存并离开”后列表显示新标题，再将本地测试标题恢复。没有公开发布测试内容。
7. 聊天设置在电脑和手机均只显示真实单图、操作帮助、补充记忆与积分；单图打开正确立绘，关闭回到设置，设置关闭后焦点回原按钮。原话记事与手动补充记忆分别标明用途。手机返回箭头实测回到同一人物，点击区为 44×44。

刷新离开的 `beforeunload` 事件有 DOM 回归覆盖。CUA 的自动化 `reload()` 没有呈现浏览器原生确认界面，不将此操作当作原生确认弹窗已验证的证据；没有声称浏览器强制关闭或移动端回收页面能够保证保住未保存输入。

旧版本留下的无索引历史记录采用先保存私有草稿、再继续原历史栈的回退。保存失败且浏览器不提供原生历史索引时，只替换当前历史项为编辑器，保住表单和前进记录；这个极端组合可能留下重复的编辑器历史项，不会假报已保存。相关登录、恢复和历史失败状态通过模拟 DOM / worker 验证，不代替真人 Firebase 验收。
