# StoryDate 首个角色闭环体检

2026-11-12，Codex，任务 [#146](https://github.com/storyloveai/ocai/issues/146)。
正式站 https://storydate-zhou.vercel.app ，核对 main `c688a97`。汐川页面与统计脚本的线上哈希均和该提交一致。

**结论：现有聊天、剧情和本机续玩已经能用；夏知遥的站外角色入口、经历互通和内容付费仍需接通。优先复用现有能力，做一段完整体验。**

| 路径 | 判定 | 实测与影响 | 下一步 |
| --- | --- | --- | --- |
| 首页进入汐川 | 能用 | 热门榜第二张卡片可打开游戏，进入序章并作选择 | 保留入口，补角色页导流 |
| 角色页认识夏知遥 | 断了 | 当前目录有 12 个角色，夏知遥缺席 | 用现有设定和定稿立绘补独立卡片 |
| 聊天及游戏内对话 | 能用 | 沈砚舟收到真实模型回复，记事刷新仍在；汐川序章也能向夏知遥自由输入并收到回应 | 复用对话组件和汐川人物设定 |
| 聊天进入故事，再回来 | 断了 | 夏知遥尚无站点聊天身份；汐川独立页面内缺少返回角色聊天的入口。聊天页“继续故事”实际为续写当前对话 | 两个入口明确区分，并携带同一人物和故事进度 |
| 保存及再次找到进度 | 半成品 | 汐川本机保存后刷新可续玩，但网站历史只列出刚才的角色聊天；`xc.*` 存档未接账号同步 | 游戏接入历史和账号存档，并设计游客转登录时的进度承接 |
| 选择时存档、标题页回想 | 断了 | 选择菜单盖住底栏，点击存档/读档无反应；标题页点回想，面板被标题层遮住 | 两处层级问题先修，桌面与手机复测 |
| 经历带回聊天 | 断了 | 游戏的 `V.said`、状态变量与站点角色记事各自保存，未发现桥接 | 先只同步一个真实剧情约定，回聊和刷新后都能引用 |
| 积分及下一段付费 | 半成品 | 实时配置为 live，有购买页；关于积分明确写当前聊天不扣积分。汐川未接内容解锁 | 先确定免费段落、付费内容及退款后权益，再接一道解锁 |
| 统计及社区 | 半成品 | 已有 PostHog、聊天/三国/支付事件，汐川缺乏相应漏斗；社区实际有一条公开作品和创建入口 | 复用统计接汐川事件，验收实际收数；社区暂作次入口 |

**下一块的最小范围。** 夏知遥卡片及独立聊天 → 进入现有汐川 → 作出一次剧情约定 → 回聊时记住具体约定 → 历史可续玩。之后在选定的章节边界接一次内容解锁。角色卡对齐讨论稿 [#144](https://github.com/storyloveai/ocai/pull/144)，先复用一个人物。

**验收。** 真实用户能找到夏知遥并完成以上路径；约定有对应剧情来源，刷新后仍在；游客登录后可选择接续本次进度；付费后权益仅增加一次。记录认识角色、首次发送成功、进故事、关键选择、回聊成功、续玩及解锁完成，使用不含台词的事件。

**验证边界。** 本次检查到序章和首个选择，未完整打通个人线。Google 登录尝试未完成，原因未确认；跨账号、跨设备、实际支付、到账及付费权益仍待真人验收。公开配置不等于支付成功，PostHog 脚本存在不等于漏斗已收数。

步骤、源码依据和截图见 [体检证据](storydate-loop-audit-2026-11-12/README.md)。
