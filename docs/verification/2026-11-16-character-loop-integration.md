## 组合来源与新增范围

固定来源：main `c688a97`，#151 `4e78a6a`（已包含 #149 `38b6ad4`），#155 `1b184f9`。在独立分支组合已有工程，不改三条源分支，不配置任何密钥或开启正式扣费。

本轮新增：

- 唯一角色目录 `/characters`；侧栏、页脚、搜索/旧卡片及聊天返回链接使用同一档案。旧 `/character`、全部 13 个旧角色详情 ID 兼容，保留查询/锚点；未知创作者角色继续原详情路径。
- 目录 ID 与原 `chatId` 显式关联，聊天和分支、记事、历史继续使用原存储键。保留周瑜/吕布/貂蝉原有聊天能力，不因缺精细人设表而丢入口。
- 夏知遥档案提供“聊天 → 故事 → 回看经历”；显示本设备或当前账号的续聊/续玩状态、当前存档事实、当前分支有效钉记事。恢复账号期间不读取或展示上一账号的私有内容。
- 汐川作品和五个人物的所有出场入口统一到 `/play/xichuan`。宿主提供回档案/回聊天，继续使用既有存档桥；旧静态链接经 307 进入宿主，iframe 的 `?site=1` 不重定向。
- 夏知遥默认明确标示的本地演示对话，不调用模型或积分接口。演示从实际存档与有效用户记事生成有限回复，不写剧情关系或事件。逐条保留演示来源标签。AI 仍复用既有服务器、报价与结算，只有已配置且用户明确切换后才使用。

## 用户从头体验

1. 左侧“角色”进入统一目录，打开夏知遥。
2. 点“开始聊天”，说一句话，在消息旁点“记住”。默认界面明确显示“本设备体验 / 演示回复 / 不调用 AI”。
3. 点“走进她的故事”，开始现有完整汐川。在第一章选择“当场填表”加入电影社。
4. 点“和夏知遥聊聊”回来，进度和推荐回复反映入社事实；对话记事保留。
5. 回人物档案查看共同经历；刷新或离开后，点“继续聊天 / 继续故事”承接同一段进度。
6. 用游戏自己的读档功能回到序章，当前共同剧情不再显示入社事实；聊天原文和钉记事保留，新的回复不将已放弃分支当作当前已发生剧情。

不会为“从头体验”清空旧聊天或旧存档。新预览域名初始无进度，已有数据的用户可用游戏原有的新游戏/读档操作。
