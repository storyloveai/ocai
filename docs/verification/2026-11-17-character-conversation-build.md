# 对话主导的角色体验重建验收

任务 #156 / PR #157，2026-11-17。根据用户“角色减法后单薄、与故事不统一、第一意图应为对话”的反馈，重建角色与 Story 详情的展示和衔接。产品取舍见 [设计说明](../product/2026-11-17-character-conversation-first.md)。继续同一 Preview，不合并。

## 最终行为

- 角色目录保留原貂蝉 banner 和既有封面卡，明确“和 TA 聊聊 / 故事出场”；仍从同一个人物档案进入，不点击卡片自动发话。
- 人物首屏恢复场景图、标准形象、公开介绍和有出处的原作台词。完整秘密设定显式折叠，未改剧本或人物内容。可聊人物无论是否已有故事进度，聊天始终是唯一白色主操作。
- 现有起聊问题仅填入输入框。输入非空时，主操作与表单都把同一句带入原聊天的本设备草稿；空白时直接开始 / 继续原对话。语言和同账号状态更新保留输入，换号清空，旧页面事件不能交接到新账号。
- 人物的原故事移至下方真实封面横卡，保留简介、详情、当前进度和原播放器。没有假世界、创作、授权或关系数值。
- 原 Story 详情将唯一剧情操作提前到封面和简介旁，角色用同一场景图、名字和线索展开；保留收藏状态、真实作者链接和原公开内容。手机补回同一套语言控件。
- 暂无独立聊天的 20 人保持完整人物展示并标明能力，通过原故事认识；13 位可聊人物保留真实 chatId。页内“在故事中认识 TA”只滚动并聚焦真实故事区域，不被全局 SPA 当新路由处理，不丢返回来源。
