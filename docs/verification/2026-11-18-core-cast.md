## 交互验收

- **目录筛选。** 实点全部七颗胶囊，依次得到 18、13、3、9、3、2、1 张卡片。点进角色再返回可恢复所选世界。旧目录链接中的页内搜索参数会清除，保留有效的世界、聊天筛选及其他 URL 参数。全站搜索仍可使用。
- **两处角色卡。** 同一人的目录卡与 Story 卡显示相同的能力、代表台词和身份。没有现成对话样例的角色使用现成的人设句。台词最多两行，能力徽章位于图内左上。汐川的三张登场卡分别可打开夏知遥、沈澄和季白。
- **排版。** 1366 px 桌面中英文七颗胶囊均完整可见。390 px 手机上的胶囊保持单行，可横滑至最右的贝克街。卡面留出徽章位置，避免遮挡透明人物立绘的眼睛。
- **手机起聊。** 390×844 下，输入框和白色主按钮各占一行，实测均宽 290 px，垂直间隔 10 px。话题按钮圆角 10 px，内边距上下 8 px、左右 12 px。中英文长话题均可原样带入聊天草稿，等待用户确认发送。
- **验收环境。** 桌面和手机截图来自本机 Chrome，使用独立浏览器上下文与隔离的本地站点。两种视口各走中英两遍，四组操作均为 0 个页面异常、0 个 POST 请求。

320×844 和 390×844 下另检查了 13 位可聊人物的中英文空白与草稿状态。两种宽度各 52 组，首屏按钮均可完整点击。

## 工程检查

`npm run build`、`npm run game:check`、三份修改样式表的 esbuild 解析及 `npm run check` 全部通过。完整套件共 375 项，覆盖草稿的账号与分支隔离、读旧档回退、来源白名单、积分门禁，以及本轮筛选、角色名单与布局。
