# 第二轮减法：先开始体验，再按需展开

任务 #156 / PR #157，2026-11-17。用户继续要求减法；仍在 `codex/character-loop-integration-20261116`，不合并 main。上一轮记录见 [角色与故事入口减法验收](2026-11-17-character-simplification.md)。

## 这一轮收掉什么

- 目录保留原貂蝉 banner 和 33 个角色的 Story 封面卡。移除重复的标题引导、每个分类的计数和桌面作品按钮排；电脑、手机共用搜索、一个作品选择器、可聊天筛选和一处结果数。筛选 URL、返回和清除条件继续使用同一套逻辑。
- 人物档案固定使用标准立绘，撤下表情演示缩略条；手机把开始 / 继续聊天和故事操作放到名字后面。没有经历时不铺空进度、空记事和设备说明。
- 原作节选直接保留一条，其他口吻、人物背景及节选合入“关于 TA”；不把模型内部不可改设定展示给读者。撤下重复的同故事人物大卡横排，其他人物仍从目录和原 Story 详情可达，不同作品的出场链接保留。
- 共同经历只在有真实剧情事实、原话记事或补充记忆时出现，默认折叠；去掉其中重复的章节进度与空记事说明。切语言和同账号异步更新保留用户的展开选择，换号不继承私有经历的开态。
- 夏知遥聊天的故事入口缩为进度和进入 / 继续故事操作，删除聊天开场里的重复进度和桥接长说明；原有剧情事实仍进入上下文。
- 模式切换只保留顶部入口。演示回复仍明确标注不调用 AI，真实 AI 的可用性、报价及逐条演示来源继续保留。
- 推荐回复默认收起，通过已有按钮按需展开。旧的明确显示 / 隐藏偏好和已生成缓存保留；收起时不请求后台建议，取消在途建议并拒绝迟到结果。个人设置使用相同默认值。
- 聊天没有原话、记事或额外分支时，撤下空回顾、零记事和单分支按钮。有内容后相应入口出现；已有其他分支仍可访问，消息旁的记住和另开走向保留。

## 验证

- `npm run build`、完整 `npm run check` **364 / 364** 通过；游戏副本一致性检查通过。修改的两份 CSS 经 esbuild 解析无警告，`git diff --check` 通过。
- 既有真实数据回归保留，新增或扩充：同账号更新和语言切换保留折叠 / 焦点、换号不继承私有开态、旧侧栏同名按钮不抢焦点、空分支仍可返回已有分支、推荐默认收起及取消在途建议、缓存不删除、迟到结果不显示也不写入。
- 报价与计费门禁、旧长记忆、源标签、存档回退、账号隔离和原有创作离开保护继续通过。没有改游戏源文件，不重复计入此前引擎模拟次数。

Chrome 实际操作（1366×900、390×844，中英双语）：

1. 同尺寸手机人物页，操作区域由约 697px 提前到约 270px；标准立绘保留，表情条与页尾角色大卡撤下。
2. 作品选择“汐川” + “可聊天” + 搜索“夏”得到 1 人；进入人物再返回，URL 和三项条件保留。切英文后条件与侧栏焦点保留；无结果可清除三项条件，回到全部 33 人并聚焦搜索框。
3. 在隔离站实际发一轮演示对话、记住用户原话、从用户原话另开空走向，再切回旧走向：原来的两条消息和一条记事保留。记事仍显示“你说过”，新空走向也能访问已有其他走向。
4. 人物共同经历默认关闭；展开并切语言后保持展开，原话不翻译，焦点留在当前页面语言按钮。没有选择隐藏的旧侧栏按钮。
5. 全新本机来源首次聊天不铺空工具、三组推荐和重复模式按钮。推荐通过原按钮展开 / 收起；唯一顶部模式入口仍明确说明演示不调用 AI，未配置的 AI 选项不可选。手机完整显示模式名称，回到底部按钮在已到底时隐藏，不再露出半个白圆。

隔离站明确关闭模型 / 计费并拒绝全部生成 POST；没有注入浏览器存档或账号数据。实际模型请求的懒加载、取消及迟到处理由 DOM / 流式模拟回归验证，不用演示回复冒充真实模型效果。
