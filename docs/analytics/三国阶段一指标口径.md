# 三国·谋士：阶段一指标口径

转正目标第一阶段要交五个数：对话轮次、次日回访、重玩率、分享率、情绪投入。这份文档说明每个数从哪些事件来、怎么算，以及在 PostHog 里怎么建图表。

## 数据从哪来

- 只统计网站上的游戏（`/play/three-kingdoms` 和水墨版）。单独打开的 `game/sanguo/web/*.html` 不上报。
- 游戏在 iframe 里，事件经 `sg2-track` 消息交给外层页面，再由外层发到 PostHog，事件名统一加 `sg_` 前缀。
  - 转发代码：`ooc-replica/sanguo/adapter.js` 的 `TRACK_FIELDS` 和 `ooc-replica/dist/assets/three-kingdoms.js` 的 `gameEvent`。
- **不发玩家说的话。** 自由发言只报长度、语气标签、显出的价值观和有没有推动剧情。外层只放行短 id、数字和布尔值，超过 60 个字的字符串一律丢掉。
- localhost、自动化浏览器和开了“请勿追踪”的访客都不统计（`analytics.js` 的 `analyticsAllowed`）。

每个 `sg_*` 事件都带这些公共字段：

| 字段 | 含义 |
|---|---|
| `game`、`edition` | `three-kingdoms`；`illustrated` 插画版 / `ink` 水墨版 |
| `vol` | 卷 id，例如 `sanguo_strategist_v1` |
| `ch` | 第几章，从 0 开始 |
| `run` | 这一局的随机 id |
| `n` | 这位访客在这台设备上开的第几局；`n>1` 说明以前玩过 |
| `lang` | `zh` / `en` |
| `ai` | 当时 AI 对白是否可用 |

## 事件表

| 事件 | 什么时候发 | 字段 |
|---|---|---|
| `game_opened` | 进入游戏页 | `edition`、`lang` |
| `sg_run_start` | 开新的一局 | `from`：接着哪一局往下玩，`null` 表示从头开始；`preset`：用的哪个前情 |
| `sg_run_branch` | 结局页点“再玩一次”，或者从某一章重开 | `chapter` |
| `sg_chapter` | 进入新的一章 | `chapter` |
| `sg_choice` | 点了一个选项 | `node`、`choice`、`via`（`button` 点按钮 / `matcher` 打字匹配到） |
| `sg_answer` | 回答了角色的提问 | `node`、`answer`、`via`、`len` |
| `sg_free_text` / `sg_talk_free` | 打字（场景里 / 夜谈里） | `node`、`matched`、`via`、`intent`、`len` |
| `sg_speech` | 每一句自由发言结算后（上面两种都会触发） | `to` 对谁说；`tone` 语气；`mood` 对方的情绪；`values` 话里显出的价值观；`move` 推动了哪条剧情；`voiced` 是不是 AI 生成的回话；`len` 字数 |
| `sg_speech_move` | 话推动了剧情 | `node`、`move`、`to` |
| `sg_talk` | 点了一个夜谈话题 | `node`、`topic`、`via` |
| `sg_ending` | 一卷结束 | `frags`（拿到的结局片段）、`deviation`、`uncanny` |
| `sg_share` | 点了结局页的“分享这个结局” | `where`、`how` |
| `game_shared` | 外层页面实际分享或复制链接之后 | `how`：`shared` 系统分享 / `copied` 复制链接 / `cancelled` 取消 / `failed` 失败 |
| `sg_tab`、`sg_map_view` | 切换面板、看地图 | |

`tone` 的取值：`warm` 温和、`flat` 平常、`flatter` 恭维、`romantic` 示爱、`rude` 冒犯、`threat` 威胁、`nonsense` 不知所云。

## 五个指标

按“访客”计数，即 PostHog 的 unique users。周报默认按周统计；单独拿出来的话，写清楚统计的日期范围。

### 1. 对话轮次

- **主口径**：开过一局的访客里，人均自由发言次数，即 `sg_speech` 总数 ÷ 发过 `sg_run_start` 的访客数。
- **辅助口径**：
  - 人均总交互 = `sg_speech` + `sg_answer` + `sg_choice` + `sg_talk`；
  - 每局自由发言数：按 `run` 分组算 `sg_speech` 的中位数；
  - AI 接住的比例：`voiced=true` 占 `sg_speech` 的比例，用来看 AI 有没有掉线。

### 2. 次日回访

- **口径**：第 0 天发过 `game_opened` 的访客，第 1 天（自然日）又发了 `game_opened` 的比例。
- **建法**：PostHog → Retention，起始事件和回访事件都选 `game_opened`，按天。
- **注意**：网站的 PostHog 设置是 `person_profiles: 'identified_only'`，没登录的访客不会建 person。上线后要先确认留存图能统计这些匿名访客；统计不到的话，有两个办法：
  - 改成 `always`：会增加计费的 person 数，要先和曹老师确认；
  - 只看登录用户的留存。

### 3. 重玩率

- **口径**：打完至少一卷（发过 `sg_ending`）的访客里，又重开了同一卷的比例。重开指以下任一：
  - 发了 `sg_run_branch`；
  - 发了 `sg_run_start`，且 `from` 为空、`n>1`。
- 接着下一卷往下玩（`from` 不为空）算**继续**，不算重玩，单独报“续卷率”。
- **建法**：Funnel，第一步 `sg_ending`，第二步 `sg_run_branch`，时间窗 7 天。从头再开的那种用 Trends 加筛选另外算，两个数相加时注意去重。

### 4. 分享率

- **口径**：打完至少一卷的访客里，点了“分享这个结局”的比例，即发过 `sg_share` 的访客数 ÷ 发过 `sg_ending` 的访客数。
- **分享成功率**：`game_shared` 里 `how` 为 `shared` 或 `copied` 的占比。
- 目前只能统计分享出去的动作，统计不到别人点开链接回流。要看回流，需要在链接上带来源参数，这一项还没做。

### 5. 情绪投入

没有直接的数，用下面四个代理指标，一起看趋势：

| 代理指标 | 算法 | 为什么能反映投入 |
|---|---|---|
| 自由发言平均长度 | `sg_speech` 的 `len` 均值 / 中位数 | 愿意多写，说明在认真对话 |
| 带情绪的话占比 | `tone` 属于 romantic、rude、threat、flatter、warm 的 `sg_speech` 占比 | 冲角色发火、示好、威胁，说明把角色当真人 |
| 话推动剧情的比例 | `sg_speech_move` ÷ `sg_speech` | 玩家在试着用话改变故事 |
| 夜谈参与 | 人均 `sg_talk` + `sg_talk_free` | 不推主线、只想和角色多说几句 |

另外可以参考两项：
- 每局时长：PostHog 的会话时长；
- 内测问卷：结局页的 `#playtest` 问卷，目前只存本地，网站上没有。

## 还没覆盖的

- **分享回流**：分享出去的链接没带来源参数，统计不到有多少人从分享进来。
- **跨设备**：没登录的玩家换一台设备，就算另一个人。
- **单机版和 Codex 的工程验收环境**：不上报。
